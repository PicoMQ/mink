# Contributing

Thank you for your interest in contributing to Mink.

The contributor guide lives in the docs: [Contribute](https://minkdb.com/docs/contribute). It covers the repository layout, building and testing, file formats and pull requests.

In short: small, focused PRs against `main`, and [open an issue](https://github.com/PicoMQ/mink/issues) first for anything larger than a bug fix.
